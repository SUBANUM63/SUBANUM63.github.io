## Run Locally

Clone the repository:

```bash
git clone https://github.com/SUBANUM63/SUBANUM63.github.io.git
cd SUBANUM63.github.io
```

Then open `index.html` in your web browser.

You can also use a simple local web server:

### Python

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
